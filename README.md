# .github
🚀 Θέλουμε να δημιουργήσουμε ένα ελεύθερο πρόγραμμα για τα ωρολόγια προγράμματα των σχολείων
Αναζητούμε εκπαιδευτικούς, προγραμματιστές και ανθρώπους που θέλουν να βοηθήσουν στη δημιουργία ενός σύγχρονου open-source εργαλείου για τη δημιουργία και διαχείριση σχολικών ωρολογίων προγραμμάτων.

Η ιδέα είναι να δημιουργηθεί ένα πρόγραμμα:

• δωρεάν και ελεύθερο λογισμικό

• με ελληνικό και αγγλικό περιβάλλον

• με εισαγωγή δεδομένων από LibreOffice/Excel/CSV

• με υποστήριξη σύνθετων περιορισμών

• βασισμένο σε σύγχρονες τεχνολογίες Python/PyQt6

• με δυνατότητα αξιοποίησης υπάρχοντος open-source timetable engine

• αναπτυσσόμενο από εκπαιδευτικούς και προγραμματιστές από την κοινότητα

Δεν χρειάζεται να είσαι προγραμματιστής για να συμμετέχεις.

Χρειαζόμαστε ανθρώπους που μπορούν να βοηθήσουν με:

👨‍💻 προγραμματισμό

🏫 εκπαιδευτικές ανάγκες και πραγματικά σενάρια σχολείων

🧪 testing

🌍 μεταφράσεις

📚 documentation

🎨 σχεδιασμό του περιβάλλοντος

Η ανάπτυξη θα γίνεται δημόσια, ώστε όποιος ενδιαφέρεται να μπορεί να βλέπει τον κώδικα, να προτείνει αλλαγές και να συμμετέχει.

Αν ενδιαφέρεσαι να συμμετάσχεις, γράψε ένα σχόλιο ή στείλε μήνυμα.

Στόχος: να δημιουργήσουμε ένα εργαλείο που θα ανήκει στην κοινότητα και όχι σε μία εταιρεία.
